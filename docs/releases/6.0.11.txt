===========================
Django 6.0.11 release notes
===========================

*December 2, 2026*

Django 6.0.11 fixes two security issues with severity "high", one security
issue with severity "moderate", four security issues with severity "low", and
several bugs in 6.0.10.

Bugfixes
========

* Fixed a regression in Django 6.0.10 where a :exc:`RecursionError` from a
  GeoJSON value was not reraised as a
  :exc:`~django.core.exceptions.ValidationError` by the
  :class:`~django.contrib.gis.forms.GeometryField` form field
  (:ticket:`37491`).

* Fixed a regression in Django 6.1.2 where ``HttpRequest.accepted_types``
  raised an exception when the ``Accept`` header contained a media range that
  could not be parsed (:ticket:`37538`).
